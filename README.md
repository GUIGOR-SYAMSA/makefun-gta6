# Solmar Heat

[make.fun GTA 6 bounty](https://make.fun/bounty/gta6-01)

Solmar Heat is a 3D coastal-city open-world driving game that runs entirely in the browser (Three.js, no network needed): drive and walk around Solmar, traffic and pedestrians, a wanted/police system with pursuits and BUSTED/WASTED, punch + pistol combat, health regen, and Mara's 3-job mission chain (pickup, delivery under heat, escape) plus repeatable jobs, with procedural WebAudio sound and music and a save system.

## How to run

Serve the `game/` folder with any static server (for example `cd game && python3 -m http.server 8080`, then open http://localhost:8080) — no build step, no install.

## Controls

WASD drive, E enter/exit car, F punch, G pistol, M mute, Shift run, Space jump, Esc pause.
